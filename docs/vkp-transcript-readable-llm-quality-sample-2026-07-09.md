## 结论

1. **标点/断句 LLM 后处理有效**：能把本地 ASR 后处理稿从“长句堆叠”提升到可阅读逐字稿，标点密度和段落语感明显改善。
2. **它不能替代术语/专名语义仲裁**：`买虫的 -> 买重的` 没被修正，说明 readable LLM 遵守了“不做事实纠错”的边界，或者缺少足够证据。
3. **`同意心 -> 同理心` 被修正**：这类上下文强、风险低的语义错词，LLM-readable 已有一定修正能力，但不能依赖它覆盖全部错词。
4. **下一步质量提升关键**：把 `买虫/买重`、`二则一/二择一`、`明晚八点/明晚八点 OK` 这类疑点进入 `evidence-conflict-index -> semantic arbitration`，由 OCR/字幕/上下文/术语词典/LLM 仲裁共同决定。
